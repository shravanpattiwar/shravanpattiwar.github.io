DATASET

Dataset Overview

RokokoHand-Motion is a high-frequency hand motion dataset collected using the Rokoko Smartglove. The dataset is designed for future motion prediction, teleoperation, robotic manipulation, delay compensation, reinforcement learning, and dexterous control.
